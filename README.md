                                                              🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built using HTML, CSS, and JavaScript. It helps users analyze resumes, calculate ATS scores, compare resumes with job descriptions, detect missing skills, and generate career recommendations.

🚀 Features

📊 ATS Score Calculator

- Checks contact information
- Checks projects section
- Checks education and experience
- Checks certifications
- Calculates an overall ATS score

🎯 Resume vs Job Description Matching

- Compare resume with a job description
- Calculate Job Match Percentage
- Identify matching skills

🔍 Missing Skills Detector

- Finds skills required by the job but missing from the resume
- Suggests skills to learn

💡 Resume Improvement Suggestions

- Suggests adding projects
- Suggests certifications
- Suggests internships
- Suggests action verbs and achievements

❌ Weak Content Detector

Detects phrases like:

- "I am hardworking"
- "I am a quick learner"

Suggests replacing them with measurable achievements.

🤖 Interview Question Generator

Generates interview questions based on:

- Skills
- Projects
- Technologies
- Career interests

🗺️ Career Roadmap Generator

Provides learning roadmaps for:

- Frontend Development
- Full Stack Development
- AI/ML
- Cybersecurity
- Cloud Computing

⬇️ Download Report

Downloads:

- ATS Score
- Job Match Score
- Career Roadmap
- Resume Analysis Summary

▶️ How to Run

1. Download the project.
2. Extract the ZIP file.
3. Open "index.html" in any browser.
4. Paste your resume and job description.
5. Click the buttons to analyze your resume.

---

🌐 Deploy on GitHub Pages

Step 1

Create a new repository named:

AI-Resume-Analyzer

Step 2

Upload:

- index.html
- style.css
- script.js
- README.md

Step 3

Go to:

Settings → Pages

Step 4

Under Build and Deployment:

Source: Deploy from a branch

Branch: main

Folder: /(root)

Click Save.

Step 5

Wait 1-2 minutes.

Your website will be available at:

https://yourusername.github.io/AI-Resume-Analyzer/
